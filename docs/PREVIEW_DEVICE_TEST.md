# 미리보기 배포 실기기 시험 체크리스트

미리보기 주소 **https://follow-the-lights.vercel.app** 에서 실제 기기로 확인할 항목이다. 허브 없이 클라우드
(Vercel + Supabase)에 키오스크·휴대폰·관리자·미디어월을 바로 붙인다. 허브까지 넣은 현장 시험은
`docs/REHEARSAL.md` 에서 따로 한다.

- 이 문서의 항목은 **사람이 실제 기기로 해야 통과로 친다**. 자동 시험이나 헤드리스 브라우저로 대신하지 않는다
  (`docs/DEPLOYMENT.md` 4·5·7절).
- 사람: 진행 1, 스태프 역할 1, 손님 역할 2~3명
- 기기: iPad(Safari), 스태프 휴대폰, 손님 휴대폰(아이폰 1대 이상, 안드로이드 1대 이상, 카카오톡·네이버 앱
  설치), 미디어월로 쓸 TV나 모니터와 PC
- 기록: 칸마다 결과(됨 / 안 됨 / 메모), 기기 모델, OS 버전, 브라우저 버전, 화면 사진. 끝나면
  `docs/STATUS.md` 와 PR에 옮긴다.
- **시험용 사진만 찍는다.** 실제 손님 사진은 넣지 않는다. 끝나면 9번 정리를 한다.

## 3. 손님 휴대폰: 셀룰러로 QR 저장

**와이파이를 끄고** LTE/5G로 한다. 브라우저마다 촬영을 새로 해서 QR을 따로 받는다.

| #   | 기기와 브라우저                                                      | 할 일                                                                                                   | 볼 것                                                                 | 결과 |
| --- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ---- |
| 3-1 | 아이폰 기본 카메라 → Safari                                          | iPad에서 **휴대폰으로 받기** → QR 비추기 → 열린 주소 확인                                               | `https://follow-the-lights.vercel.app/p/...` 인지(로컬 주소가 아닌지) |      |
| 3-2 | 아이폰 Safari                                                        | **사진 저장하기** → 공유 메뉴 → **이미지 저장**. 사진을 길게 눌러 **사진 앱에 저장** 도 해 본다         | 사진 앱에 들어갔는지, 화질, 걸린 시간                                 |      |
| 3-3 | 안드로이드 기본 카메라(또는 구글 렌즈) → Chrome                      | QR 비추기 → **사진 저장하기**                                                                           | 갤러리나 다운로드 폴더에 저장되는지                                   |      |
| 3-4 | 카카오톡 앱 안에서 QR 스캔(더보기 → 코드 스캔), 아이폰과 안드로이드  | 카카오톡 안의 브라우저로 열고 저장. 안 되면 **파일로 받기**, 그래도 안 되면 다른 브라우저로 열기를 시험 | 어느 방법으로 저장됐는지, 막힌 단계                                   |      |
| 3-5 | 네이버 앱 안에서 QR 스캔(그린닷 → 렌즈 또는 QR), 아이폰과 안드로이드 | 3-4와 같다                                                                                              | 같다                                                                  |      |
| 3-6 | 아무 휴대폰                                                          | 저장한 QR 링크를 1시간 뒤에 다시 연다                                                                   | 열리는지(링크 유효 시간 72시간)                                       |      |
| 3-7 | 아무 휴대폰                                                          | 주소 끝 몇 글자를 바꿔서 연다                                                                           | "사진을 찾을 수 없어요". 다른 사진이 보이면 안 된다                   |      |

**미디어월 질문은 두 갈래 모두 해 본다.**

| #    | 할 일                                            | 볼 것                                                             | 결과 |
| ---- | ------------------------------------------------ | ----------------------------------------------------------------- | ---- |
| 3-8  | 한 번은 **아니요, 사진만 저장할게요**            | 휴대폰 링크가 그대로 열리는지. 관리자 **검수** 에는 나오지 않는지 |      |
| 3-9  | 다른 한 번은 **네, 함께 보여주세요**             | 관리자 **검수** 에 **검수 대기** 로 나오는지                      |      |
| 3-10 | 두 버튼의 크기·색·위치를 손님 역할이 보고 말한다 | 한쪽으로 유도하는 느낌이 없는지                                   |      |

## 5. TV·모니터 미디어월

**등록 코드:** 15분 후 만료되므로 1-4에서는 발급하지 않고 5-1 직전에 새로 발급한다.

**빈 화면 확인:** 4-1에서 승인한 사진을 5-3 전에 관리자에서 임시 숨긴다. 5-3의 빈 풍경을 확인한 다음, 5-4에서 같은 사진을 다시 보이도록 전환한다.

| 5-9  | 손님이 설 자리(가까운 곳, 먼 곳)에서 본다                                                        | 얼굴을 알아볼 수 있는지, 밝기                                          |      |
| 5-10 | 1시간 켜 둔다                                                                                    | 멈추거나 느려지지 않는지. 관리자 **키오스크** 의 fps·메모리 기록       |      |

## 6. 현장 와이파이 장애 연습

미리보기에는 허브가 없어서 iPad가 인터넷에 바로 붙는다. 허브와 공유기를 함께 끊는 연습은
`docs/REHEARSAL.md` E절에서 한다.

| #   | 할 일                                                              | 볼 것                                                                                                    | 결과 |
| --- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | ---- |
| 6-1 | iPad 와이파이를 끈 채 촬영하고 **휴대폰으로 받기**                 | "네트워크 연결을 확인하고 있어요", 사진은 기기에 보관한다는 안내. 가짜 QR이 나오지 않는지                |      |
| 6-2 | 와이파이를 다시 켠다                                               | 누르지 않아도 사진을 보내고 같은 화면에 QR이 나오는지, 걸린 시간                                         |      |
| 6-3 | 와이파이를 끈 채 두 팀 촬영 → **QR 없이 다음으로** → 와이파이 켜기 | 화면 위 **전송 대기 N건** 이 0이 되는지. 관리자 **최근 세션** 에 두 건이 오는지(QR 다시 보여주기로 복구) |      |
| 6-4 | 보내는 도중 Safari를 닫았다가 다시 연다                            | 보관한 사진이 사라지지 않고 다시 보내지는지                                                              |      |
| 6-5 | 공유기 전원을 1분 끈다(iPad·벽 PC 동시에 끊김)                     | 6-2와 5-8이 동시에 일어나는지. 손님 휴대폰(셀룰러)은 영향이 없는지                                       |      |
| 6-6 | 휴대폰 핫스팟으로 iPad를 붙여 본다(공유기 고장 대비책)             | 촬영과 QR이 되는지                                                                                       |      |

## 7. 결과 정리

- 모든 칸을 채우면 `docs/STATUS.md` 의 해당 항목과 `docs/DEPLOYMENT.md` 상태 줄을 바꾼다.
  - 3번 전부 됨 → `REAL_PHONE_CELLULAR_TEST: VERIFIED (기기 목록)`
  - 1·4번 전부 됨 → `REAL_STAFF_DEVICE_TEST: VERIFIED`
  - 5번 전부 됨 → `REAL_WALL_DISPLAY_TEST: VERIFIED` (단, 실제 LED 시험은 `docs/REHEARSAL.md` D절)
- 안 된 항목은 그대로 두고, 무엇이 막혔는지와 할 일을 적는다.

## 8. 하지 않는 것

- 휴대폰 번호·이메일 등 손님 연락처를 받지 않는다. 인쇄도 하지 않는다.
- 스태프 계정 비밀번호·등록 코드를 단체 대화방에 올리지 않는다. 코드는 15분 뒤 저절로 못 쓰게 된다.
- 관리자 **설정** 의 행사 종료 처리는 누르지 않는다(`docs/STATUS.md` "출시 전 남은 차단 항목").

## 9. 끝난 뒤 정리

- 관리자 **사진** 에서 시험 사진을 모두 **삭제** 한다(이미지와 링크가 함께 지워진다).
- 시험에 쓴 키오스크와 미디어월을 **등록 해제** 한다. 실제 행사 기기는 행사 전에 새로 등록한다.
