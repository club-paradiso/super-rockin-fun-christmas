# 원격 카메라 — 봉사자 안내 (한 장)

아이폰이 부스의 **카메라**, 아이패드가 **화면**입니다. 손님은 아이패드만 만집니다.
이 안내는 실기기에서 아직 확인 전입니다. 이상하면 맨 아래 **"안 될 때"**를 보세요.

## 처음 켤 때 (스태프 한 명, 5분)

1. **충전기 두 개**를 아이패드와 아이폰에 꽂습니다.
2. **아이폰** 설정 → 디스플레이 및 밝기 → **자동 잠금: 안 함**. (이걸 안 하면 화면이 잠겨서 사진이 안 찍혀요!)
3. **아이폰 Safari**로 운영 주소 뒤에 `/camera/remote`를 엽니다.
4. **관리자 화면**(`/admin`) → **원격 카메라** → 부스를 고르고 **연결 코드 만들기**. 8자리 코드(또는 QR)가 나와요.
   코드는 **10분, 한 번만** 쓸 수 있어요.
5. 아이폰에 코드를 넣고 **연결하기** → **카메라 시작** → 카메라 **허용**.
6. 아이폰에 **"대기 중"** 또는 **"연결됨"**이 보이면 성공. **화면 어둡게**를 눌러 둡니다(덜 뜨거워져요).
7. 아이폰 **안내 접근**(설정 → 손쉬운 사용 → 안내 접근)을 켜고 이 화면에서 시작하면 실수로 나가지 않아요.
8. 아이패드는 부스 주소 끝에 **`?camera=remote`**를 붙여 열어 둡니다. (예: `https://….vercel.app/kiosk?camera=remote`)

## 매일 시작 (2분)

- 두 기기 모두 **충전 중 · 화면 켜짐**.
- 아이폰 화면: **"대기 중"**. 관리자 → 원격 카메라 → **마지막 신호가 몇 초 전**인지.
- 관리자에서 **테스트 촬영** → 작은 사진이 뜨면 OK.
- 부스에서 **한 번 끝까지** 찍어 보고 QR이 나오는지 확인.

## 매일 끝

- 부스를 **처음 화면**으로 두세요. 아이폰 **"연결 해제"는 누르지 마세요**(다음에 다시 코드가 필요해요).
- 행사가 다 끝나면 관리자에서 **페어링 해제**.

## 설치할 때 꼭

- 아이폰 **뒷면 카메라(렌즈)**가 손님을 보게, 렌즈를 **마른 천으로 닦고** 유리에 반사가 없게.
- 높이는 손님 **눈높이**쯤, 머리부터 어깨까지 들어오게. 테스트 촬영으로 확인.
- 충전선은 **당겨도 안 빠지게** 고정. **통풍구를 막지 마세요.** 아이폰이 뜨거우면 관리자에서 **화질 모드 → 표준/절전**.
- 아이폰·아이패드 **둘 다 같은 Wi-Fi**. 공용 Wi-Fi는 서로 못 찾는 경우가 있어요. 전용 공유기가 가장 안전해요.

## 안 될 때 (위에서부터)

| 보이는 것                               | 하세요                                                                                                                                             |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 부스에 **"카메라를 찾을 수 없어요"**    | ① 아이폰 화면이 **켜져** 있고 **Safari 앞**에 있는지 ② 관리자의 **마지막 신호**가 오래됐는지 ③ 아이폰에서 **카메라 시작** ④ 부스에서 **다시 시도** |
| 부스 **미리보기가 멈춤**                | 관리자 → **재연결**. 아이폰이 뜨거우면 식히고 화질 모드 낮추기                                                                                     |
| 아이폰에 **"카메라 사용이 거부됐어요"** | 설정 → Safari → 카메라 → **허용**, 페이지 새로고침                                                                                                 |
| **"코드가 틀렸거나 만료"**              | 관리자에서 **새 코드** 만들기                                                                                                                      |
| 계속 안 됨                              | **아이패드 주소에서 `?camera=remote`를 지우고** 다시 열기 → 아이패드 자체 카메라로 촬영 (임시 대안)                                                |
| 그래도 안 됨                            | 기술 담당에게 연락. 관리자 화면의 **오류 문장**을 알려 주세요                                                                                      |

## 하면 안 되는 것

- 아이폰의 **잠금 버튼**을 누르지 마세요(잠기면 사진이 안 찍혀요).
- 아이폰에서 다른 앱을 열지 마세요.
- 손님이 아이폰을 만지게 하지 마세요.
- 코드를 사진으로 남기거나 단체방에 올리지 마세요(10분 지나면 쓸모는 없지만 그래도요).
