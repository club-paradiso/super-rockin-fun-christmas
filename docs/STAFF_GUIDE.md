# 봉사자 안내: 사진 부스와 미디어월

Christmas Village 봉사자용입니다. 컴퓨터를 잘 몰라도 됩니다. 순서대로만 하세요.
막히면 맨 아래 "문제가 생겼을 때"를 보고, 그래도 안 되면 기술 담당에게 연락합니다.

> 이 문서의 화면 이름은 관리자 화면(`/admin`)에 실제로 적힌 그대로입니다.
> 자동 확인(AI) 부분은 2026-11-14에 Claude가 썼고, 교회 확인 전입니다.

## 꼭 기억할 세 가지

1. **이상한 사진이 미디어월에 보이면 → "미디어월 일시정지"부터 누릅니다.** 사진이 전부 내려갑니다. 원인은 그다음에 찾습니다.
2. **AI는 틀릴 수 있습니다.** 자동 확인을 켜 둔 날에도 누군가는 미디어월을 보고 있어야 합니다.
3. **어떤 버튼을 눌러도 손님 사진은 지워지지 않습니다.** "삭제"만 예외이고, 삭제는 한 번 더 물어봅니다.

## 1. 부스 열기

1. 부스 태블릿(또는 노트북)을 켜고 Chrome에서 부스 주소를 엽니다.
2. "화면을 눌러 시작"이 보이면 준비된 것입니다.
3. "이 기기는 아직 키오스크로 등록되지 않았어요"가 보이면 "기기 등록하기"를 누르고 등록 비밀번호를 넣습니다.
4. 직접 한 번 찍어 봅니다. QR이 나오고, 휴대폰으로 찍었을 때 사진이 열리면 됩니다.

## 2. 인터넷 확인

1. 휴대폰이나 노트북으로 관리자 화면을 엽니다. 비밀번호는 부스 등록 비밀번호와 같습니다.
2. "개요"에서 **키오스크: 1 온라인**(부스 대수만큼)인지 봅니다.
3. "오프라인"이면 부스 기기의 와이파이를 확인합니다. 인터넷이 끊겨도 촬영은 계속되고, 사진은 부스에 보관됐다가 연결되면 올라갑니다.

## 3. 미디어월 확인

1. 미디어월 컴퓨터에서 미디어월 주소를 전체 화면으로 엽니다.
2. 관리자 화면 "개요" → "긴급 제어"에서 **미디어월 켜기/끄기**가 "지금 켜짐"인지 봅니다.
3. 승인된 사진이 없으면 배경만 나옵니다. 정상입니다.

## 4. 자동 확인(AI)이 하는 일

관리자 화면 "개요"나 "검수"의 **사진 확인 방식** 칸을 봅니다.

| 화면에 적힌 말        | 뜻                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------- |
| 사람이 모두 확인      | 손님이 "네"라고 한 사진이 전부 "검수 대기"로 옵니다. 봉사자가 승인해야 미디어월에 나옵니다. |
| 자동 확인 (AI) + 사람 | AI가 먼저 봅니다. 문제없어 보이는 사진만 바로 승인됩니다. 나머지는 "검수 대기"로 옵니다.    |

- AI는 **승인만** 합니다. 반려하거나 지우지 않습니다. 애매하면 전부 사람에게 넘깁니다.
- 자동 확인을 켜면 부스 동의 화면에 "사진을 외부 AI 서비스로 보내 확인한다"는 안내가 붙습니다. 그 안내를 보고 "네"를 누른 사진만 AI로 갑니다.
- **휴대폰으로 보낸 사진은 항상 사람이 확인합니다.**
- 켜고 끄는 버튼은 같은 칸에 있습니다: "자동 확인 켜기" / "사람이 모두 확인하기로 바꾸기". 켜는 것은 기술 담당과 정한 날에만 합니다.

## 5. 사진 검수하기

"검수" 메뉴로 갑니다. 위쪽에 구역이 다섯 개 있습니다.

| 구역      | 무엇이 있나                             | 할 일                                             |
| --------- | --------------------------------------- | ------------------------------------------------- |
| 검수 대기 | 사람이 봐야 하는 사진                   | 괜찮으면 **승인**, 아니면 **반려**                |
| AI 주의   | AI가 "문제가 있어 보인다"고 표시한 사진 | 직접 보고 정합니다. AI가 틀렸으면 승인해도 됩니다 |
| AI 승인   | AI가 승인해서 미디어월에 나가는 사진    | 가끔 훑어봅니다. 이상하면 **숨기기**              |
| 반려      | 반려한 사진                             | 실수였으면 **다시 검수**                          |
| 숨김      | 미디어월에서 내린 사진                  | 다시 올리려면 **다시 보이기**                     |

사진 아래 작은 표시의 뜻:

- **AI 주의** + "AI가 본 것: 욕설 손동작" 같은 글: AI가 그렇게 봤다는 뜻입니다. 사실이 아닐 수 있으니 눈으로 확인합니다.
- **AI 판단 보류 / AI 확인 실패 / AI 확인 안 함**: AI가 답을 못 했습니다. 평소처럼 보고 정하면 됩니다.
- **AI 확인 중**: 잠시 뒤 결과가 나옵니다. 기다리지 않고 바로 승인·반려해도 됩니다. 사람이 누른 것이 우선입니다.

무엇을 반려하나: 노출·선정적인 모습, 폭력·피, 욕설 손동작, 욕이나 비방이 적힌 글자, 혐오 표현이나 상징, 그 밖에 아이들과 함께 보기 어려운 것. 판단이 어려우면 반려하고 다른 봉사자와 상의합니다.

## 6. AI가 멈췄을 때

**사진 확인 방식** 칸의 "AI 서비스" 줄에 빨간 글씨가 보이면 AI가 답을 못 하고 있는 것입니다.

- **아무것도 하지 않아도 됩니다.** 사진은 자동으로 "검수 대기"에 쌓입니다. 평소처럼 승인·반려하면 됩니다.
- 부스는 계속 됩니다. 손님은 사진을 찍고 QR을 받을 수 있습니다.
- "오늘 사용량"이 한도에 닿았다고 나와도 같습니다. 남은 사진은 사람이 봅니다. 다음 날 다시 됩니다.
- 30분 넘게 빨간 글씨면 "사람이 모두 확인하기로 바꾸기"를 누르고 기술 담당에게 알립니다.

## 7. 부적절한 사진 내리기

미디어월에 이미 나온 사진을 내릴 때:

1. "사진" 메뉴(또는 "검수" → "AI 승인")에서 그 사진을 찾습니다.
2. **숨기기** → 확인. 그 사진만 5초 안에 내려갑니다. 다른 사진은 그대로입니다.
3. 손님이 "내 사진 내려 주세요"라고 하면 똑같이 합니다. 손님 사진 파일까지 지워 달라고 하면 **삭제**(되돌릴 수 없음)를 씁니다.

어느 사진인지 못 찾겠으면 8번으로 갑니다.

## 8. 긴급 정지

"개요" 맨 위 **긴급 제어**:

| 스위치                  | 누르면                                                                 | 언제                                    |
| ----------------------- | ---------------------------------------------------------------------- | --------------------------------------- |
| **미디어월 일시정지**   | 미디어월에서 사진이 전부 내려가고 배경만 남습니다 (5초 안)             | 이상한 사진이 보이는데 바로 못 찾을 때  |
| 대기 화면 표시          | 미디어월이 안내 화면으로 바뀝니다. 사진은 안 나옵니다                  | 예배·행사 진행 중 잠시 가릴 때          |
| 미디어월 게시 신청 중지 | 부스에서 "미디어월에 띄울까요?"를 더 묻지 않습니다. 촬영과 QR은 됩니다 | 검수가 밀렸거나 봉사자가 자리를 비울 때 |

스위치가 빨갛게 "켜짐"이면 정지 상태입니다. 정지한 동안에도 부스는 정상입니다.

## 9. 다시 정상으로

1. 문제 사진을 숨기거나 삭제했는지 확인합니다.
2. "검수" → "AI 승인"을 훑어봅니다.
3. 긴급 제어의 스위치를 다시 눌러 "꺼짐"으로 돌립니다. 승인된 사진이 다시 나옵니다.
4. AI가 잘못 승인한 것이 원인이었다면 "사람이 모두 확인하기로 바꾸기"를 누르고 그날은 사람이 봅니다.

## 10. 마감

1. "검수 대기"가 0건인지 봅니다. 남았으면 승인하거나 반려합니다.
2. 미디어월을 끕니다: 긴급 제어 → 미디어월 켜기/끄기 → "끄기".
3. 부스 화면이 "화면을 눌러 시작"인지 확인하고 기기를 닫습니다.
4. 관리자 화면 오른쪽 위에서 로그아웃합니다. 공용 기기라면 꼭 합니다.

## 문제가 생겼을 때

| 증상                                      | 해 볼 것                                                                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 부스에 "등록되지 않았어요"                | "기기 등록하기" → 등록 비밀번호                                                                                          |
| 카메라가 안 나옴                          | 화면의 "다시 시도". 안 되면 Chrome 주소창 왼쪽 자물쇠 → 카메라 허용. 그래도 안 되면 새로고침                             |
| QR이 안 나오고 "QR을 준비하고 있어요"     | 인터넷이 느린 것입니다. 기다리면 나옵니다. 손님이 급하면 화면의 세션 번호를 적어 두고 나중에 "최근 세션"에서 찾아 줍니다 |
| 부스에 "사진 확인이 조금 지연되고 있어요" | 정상입니다. AI가 늦거나 사람 확인으로 넘어간 것입니다. 손님은 QR로 사진을 받아 가면 됩니다                               |
| 승인했는데 미디어월에 안 나옴             | 긴급 제어 스위치가 켜져 있지 않은지, 미디어월이 "지금 켜짐"인지 봅니다. 사진이 많으면 차례가 올 때까지 걸립니다          |
| 미디어월이 멈춘 것 같음                   | 미디어월 컴퓨터에서 새로고침(F5)                                                                                         |
| "검수 대기"가 갑자기 많이 쌓임            | 6번을 봅니다. AI가 멈췄을 가능성이 큽니다. 사람이 승인하면 됩니다                                                        |
| 관리자 화면이 로그인 화면으로 돌아감      | 다시 로그인합니다. 12시간마다 풀립니다                                                                                   |
| "자동 확인 켜기" 버튼이 안 보임           | 이 서버에 AI가 설정되지 않은 것입니다. 사람이 확인하면 됩니다. 기술 담당에게 알립니다                                    |
