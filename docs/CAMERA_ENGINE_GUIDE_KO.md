# 카메라 자동 보정 — 봉사자 안내 (한 장)

키오스크가 조금 비스듬하게 놓여 있어도 사진이 기울거나 찌그러져 보이지 않게 해 주는 기능입니다.
각도를 재거나 숫자를 넣을 필요가 없습니다. **처음에는 꺼져 있습니다.**

이 안내는 실제 아이패드에서 아직 확인 전입니다. 이상하면 맨 아래 **"안 될 때"**를 보세요.

## 순서 (5분)

1. **키오스크를 설치합니다.** 흔들리지 않게 고정하세요. 되도록 바로 세우는 것이 가장 좋습니다.
2. **STUDIO SHALOM을 엽니다.** 아이패드 Safari에서 평소 쓰는 부스 주소입니다.
3. **켭니다.** 다른 기기(휴대폰·노트북)에서 관리자 화면 → **설정** → **카메라 자동 보정** →
   **자동** → **저장**.
4. **권한을 허용합니다.** 아이패드 첫 화면("화면을 눌러 시작")을 누르면 "동작 및 방향에
   접근하려고 합니다"라는 창이 **한 번** 뜹니다. **허용**을 누르세요. 카메라 권한도 평소처럼
   허용합니다.
5. **테스트 사진을 한 번 찍습니다.** 끝까지(QR까지) 찍어 보세요.
6. **확인합니다.** 사진 속 문틀이나 벽 모서리가 똑바로 서 있으면 됩니다. 사람 얼굴이 길쭉해
   보이지 않는지도 봅니다.
7. **시작합니다.** 손님은 평소와 똑같이 찍으면 됩니다. 따로 할 일이 없습니다.

## 잘 되고 있는지 보는 곳

관리자 화면 → **키오스크** → 그 키오스크의 **자동 보정** 줄.

| 보이는 말                                | 뜻                                          |
| ---------------------------------------- | ------------------------------------------- |
| 정상 · 기울기를 보정하고 있어요          | 잘 되고 있어요                              |
| 정상 · 바로 서 있어서 보정할 것이 없어요 | 잘 되고 있어요. 키오스크가 똑바로 서 있어요 |
| 좌우 기울기만 보정하고 있어요            | 사진은 정상이에요. 앞뒤 보정만 빠졌어요     |
| 보정 안 함 · 사진은 원래대로 찍혀요      | 보정은 안 되지만 **촬영은 정상**이에요      |

**어떤 경우에도 사진 촬영과 QR은 멈추지 않습니다.** 보정이 안 될 뿐입니다.

## 매일 시작할 때

- 아이패드에서 부스를 열고 첫 화면을 한 번 누릅니다(권한 창이 뜨면 허용).
- 관리자 화면 키오스크에서 "정상"인지 봅니다.
- 한 번 끝까지 찍어 봅니다.

## 안 될 때 (위에서부터)

| 보이는 것                        | 하세요                                                                 |
| -------------------------------- | ---------------------------------------------------------------------- |
| 사진이 **더** 기울어 보인다      | 관리자 설정에서 **끄기 → 저장**. 그리고 담당자에게 알려 주세요.        |
| "센서 권한이 거부됐어요"         | Safari 탭을 닫고 부스 주소를 다시 엽니다. 창이 뜨면 **허용**.          |
| "센서 권한을 아직 묻지 않았어요" | 아이패드 첫 화면을 한 번 누릅니다.                                     |
| "키오스크가 흔들리고 있어요"     | 거치대를 고정합니다. 멈추면 1~2초 뒤 정상이 됩니다.                    |
| 사진이 많이 잘린다               | 키오스크가 너무 기울어 있습니다. 거치대를 바로 세우세요.               |
| 얼굴이 길어 보인다               | 관리자 설정에서 **앞뒤 기울기 보정**을 끄고 저장합니다.                |
| 뭔가 이상한데 모르겠다           | 관리자 설정에서 **끄기 → 저장**. 다음 손님부터 예전과 똑같이 찍힙니다. |

## 알아 두세요

- 바꾼 설정은 **다음 손님부터** 적용됩니다. 찍고 있는 손님의 사진은 바뀌지 않습니다.
- 한 손님의 여섯 장은 모두 같은 값으로 보정됩니다. 촬영 중에 누가 키오스크를 건드려도 바뀌지 않습니다.
- 이 기능은 키오스크가 **조금** 기울었을 때를 위한 것입니다. 많이 기울었으면 거치대를 고치세요.
- 카메라가 낮아서 얼굴을 올려다보는 것은 고쳐 주지 못합니다. 카메라는 눈높이가 가장 좋습니다.
- 센서 값과 사진은 이 기능 때문에 어디로도 따로 보내지지 않습니다.
