## 3. 바꾸지 않은 것 (의도적으로)

- 6장 촬영, 2~6컷 선택, 동의·검수·삭제 규칙, 키오스크/스태프 인증, 로테이션(F1~F6), 운영 시간,
  비상 스위치, 오프라인 큐, 허브 보관 규칙. 휴대폰 사진은 이 규칙 위에 그대로 올라간다.
- 폴링 구조(5초)와 벽 메모리 관리: 기존 측정에서 문제가 없었고 근거 없이 다시 쓰지 않았다.
- 디자인 원본(Figma)·로고·프레임. 새 화면은 기존 토큰(gold/navy/glow)과 버튼 클래스로 만들었다.
  **Figma 파일에 2.0 화면은 아직 없다** (design/README.md 규칙상 반영 필요 — 남은 일).

## 5. 호환성

- 데이터: 기존 사진·설정 그대로. 로컬 허브 파일에 `kioskDefaultMode`가 없으면 "standard".
  Supabase는 새 컬럼 기본값 'standard'. 휴대폰 사진은 기존 표에 들어가므로 스키마 변경 없음.
- **배포 순서**: Supabase 마이그레이션을 먼저 적용해야 한다(설정 함수 서명이 바뀜). 적용 전에 새 코드가
  돌면 관리자 설정 저장이 실패한다(읽기는 기본값으로 동작). 미리보기 Supabase에 적용하는 것은
  프로덕션 변경이라 **승인 대기**.
- 키오스크 하트비트 응답에 `kioskDefaultMode` 필드가 추가됐다(이전 부스는 무시).
- E2E의 첫 화면 버튼 이름이 "화면을 눌러 시작" → "여기서 사진 찍기"로 바뀌었다.
