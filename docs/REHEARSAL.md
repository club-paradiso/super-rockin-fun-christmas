# FOLLOW THE LIGHTS 현장 리허설 체크리스트

실제 장소에서, 실제 기기로, 행사와 같은 시간대(저녁)에 한 번 한다. 기획안 일정 기준 11/9~13(LED 실공간
시험) 주간이 맞다. 이 문서의 항목은 **실물이 없어서 지금까지 확인하지 못한 것**(`docs/STATUS.md` 의
"막힘", `docs/measurements/2026-10-13-phase4.md` 7절)을 모두 덮도록 짰다.

- 소요: 약 3시간 (마지막 "장시간 켜 두기"는 행사 시간만큼)
- 사람: 현장 책임자 1, 기술 담당 1, 스태프 2, 손님 역할 3~4명(어른, 어르신, 어린이와 보호자)
- 준비물: 부스 노트북(허브), 예비 노트북, 웹캠, 조명, 미디어월 PC, LED, 전용 공유기, USB 메모리,
  스태프 휴대폰 2대, 손님 휴대폰 3대 이상(아이폰·안드로이드, **와이파이 끄고** LTE/5G), 인쇄한 사인물
- 기록: 칸마다 결과(됨 / 안 됨 / 메모)와 사진. 끝나면 `docs/STATUS.md` 에 옮긴다. 안 된 항목은
  "막힘" 그대로 두고 할 일을 적는다.
