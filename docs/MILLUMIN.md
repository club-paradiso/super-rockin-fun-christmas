# Millumin 4로 미디어월 띄우기

Millumin 4가 LED에 화면을 내보내고, 그 안에 미디어월(`/wall`)을 넣는 방법이다.

> **검증 범위 (2026-11-28).** 이 문서의 벽 쪽 동작(전체화면 버튼 없음, 어떤 렌더 크기든 꽉 채움,
> 점검 화면)은 Chromium에서 자동 시험으로 확인했다(`e2e/wall.spec.ts` 「embed」). **Millumin 4
> 실기 시험은 하지 않았다**(Millumin은 macOS 전용이고 개발 환경에 없다). Millumin 쪽 메뉴 이름은
> 공식 도움말(help.millumin.com → Playback → Medias)의 설명을 따랐고, 그 브라우저가 어떤 엔진인지,
> 로그인 상태(쿠키)를 재시작 뒤에도 기억하는지는 문서에서 확인하지 못했다. 그래서 아래 5번 점검을
> 행사 전에 사람이 직접 해야 한다.

## 1. 주소

Millumin에 넣는 주소는 끝에 **`?embed=1`** 을 붙인다.

```
http://<허브 주소>:3000/wall?embed=1
```

`embed=1` 이 하는 일:

| 평소 브라우저                                   | `embed=1`                                                                   |
| ----------------------------------------------- | --------------------------------------------------------------------------- |
| 창이 화면보다 작으면 「전체화면」 버튼이 4초 뜸 | 버튼이 아예 없음 (새로고침 때마다 LED에 찍히는 것 방지)                     |
| 더블클릭·F 키로 브라우저 전체화면               | 아무 일도 안 함. 전체화면은 Millumin 출력이 맡음                            |
| 10초 동안 화면을 못 그리면 페이지 새로고침      | 안 함. 그리는 시점은 Millumin이 정하므로 오판하면 1분마다 새로고침되기 때문 |

`canvas=` 는 **붙이지 않는다.** 그건 모니터에서 LED 모양을 미리 보는 용도라 띠(레터박스)가 생긴다.

## 2. Millumin 설정 (방법 A: 브라우저 미디어)

1. 미디어 추가 → **Browser**(웹 페이지) → URL에 위 주소.
2. **Render size(렌더 크기)를 LED 해상도와 똑같이** 넣는다. 예: LED가 3840 × 1080이면 3840 × 1080.
   미디어월은 받은 크기를 그대로 화면으로 보고 사진 배치를 다시 계산한다. 렌더 크기의 비율이
   LED와 다르면 Millumin이 늘이거나 띠를 넣게 되고, 그게 "비율이 안 맞는" 원인이다.
3. 그 미디어를 넣은 레이어는 캔버스에 100 %로 둔다(늘이기·자르기 없이).
4. Framerate는 30 이상. 투명(alpha)은 끈다.
5. 전체화면은 **Millumin의 출력 전체화면**으로 한다. 페이지 안에서 전체화면을 찾지 않는다.

### 화면 등록 (처음 한 번)

등록하지 않은 화면은 "공개 화면"이라 **공개 동의한 사진만**, 관리자에서 공개 미디어월을 켜지 않았으면
**0장** 받는다. 사진이 한 장도 안 걸리고 배경만 보이는 가장 흔한 이유다.

1. 관리자 → 키오스크 → **등록 코드 만들기** (15분, 1회용).
2. Millumin 브라우저 미디어의 URL을 잠깐 이렇게 바꾼다(코드가 칸에 미리 들어간다):
   `http://<허브 주소>:3000/kiosk/enroll?next=wall&code=K7QM-3XRP`
3. **Brush(붓) 도구**로 화면의 **이 기기 등록** 버튼을 한 번 누른다.
4. URL을 다시 `…/wall?embed=1` 로 돌린다.

Millumin을 껐다 켠 뒤에도 등록이 남는지는 5번 점검으로 확인한다. 남지 않으면 방법 B를 쓴다.

## 3. 방법 B: Chrome 창을 화면 캡처로 가져오기

Millumin 브라우저에서 문제가 있으면(등록이 안 남음, 화면이 멈춤) 이쪽이 안전하다.

1. `ops/start-wall.command` 로 Chrome 미디어월을 **LED가 아닌 다른 화면**(보조 모니터나 가상
   디스플레이)에 띄운다. 그 화면 해상도를 LED와 같게 맞춘다. 이때 주소는 평소대로(`embed` 없이)
   둔다: 진짜 전체화면 창이라 버튼이 안 뜬다.
2. Millumin에서 미디어 추가 → **Screen capture** → 그 디스플레이(또는 Chrome 창)를 고른다.
3. Chrome 창을 다른 창으로 **가리거나 최소화하지 않는다.** 가려진 창은 브라우저가 그리기를 멈춰
   캡처 화면이 멈춘다.

## 4. 증상별 원인

| 증상                               | 가장 가능성 높은 원인                                     | 조치                                             |
| ---------------------------------- | --------------------------------------------------------- | ------------------------------------------------ |
| 배경만 있고 사진이 안 걸림         | 화면 미등록(공개 화면) 또는 승인된 사진 없음              | 점검 화면의 "이 화면", "사진" 줄 확인 → 등록     |
| 사진이 안 바뀌는 것 같음           | 정상일 수 있음: 한 장이 기본 14초 걸려 있음               | 점검 화면의 시계가 가면 정상                     |
| 시계도 멈춤                        | Millumin이 페이지를 안 그림(레이어 꺼짐, 미디어 일시정지) | 레이어 재생 상태 확인, 안 되면 방법 B            |
| 위아래·좌우에 띠, 또는 늘어나 보임 | 렌더 크기 ≠ LED 해상도, 또는 주소에 `canvas=`             | 렌더 크기를 LED와 같게, `canvas=` 삭제           |
| 구석에 「전체화면」 버튼이 찍힘    | 주소에 `embed=1` 이 없음                                  | 붙인다                                           |
| "STAFF · 연결 확인 중"             | 허브에 연결 안 됨                                         | 공유기·허브 확인. 2분 넘으면 사진이 내려감(정상) |
| 검은 화면                          | 주소 오타, 허브 꺼짐                                      | 같은 맥의 Safari로 같은 주소를 열어 본다         |

## 5. 점검 화면 (행사 전 필수)

주소에 **`&check=1`** 을 더 붙이면 벽 위에 숫자가 뜬다.

```
http://<허브 주소>:3000/wall?embed=1&check=1
```

| 줄          | 봐야 할 것                                                              |
| ----------- | ----------------------------------------------------------------------- |
| 화면 크기   | LED 해상도와 같은가. 배율이 2면 맥 레티나 배율이 걸린 것(선명도만 영향) |
| 이 화면     | **등록된 행사장 화면**이어야 한다                                       |
| 미디어월    | 켜짐                                                                    |
| 사진        | 받을 수 있는 N장 → 불러온 N장 → 걸린 N장 순서로 늘어나는가              |
| 서버 응답   | 0~5초 전을 오가야 한다                                                  |
| 화면 그리기 | 초당 30~60번. **0번**이면 Millumin이 이 페이지를 안 그리는 것           |
| 시계        | 1초씩 가야 한다                                                         |

체크리스트 (사람이 Millumin에서 직접):

- [ ] 점검 화면의 화면 크기 = LED 해상도
- [ ] "등록된 행사장 화면"으로 나옴
- [ ] Millumin을 완전히 껐다 켠 뒤에도 "등록된 행사장 화면"
- [ ] 부스에서 한 장 찍어 승인 → LED에 걸림
- [ ] 30분 그대로 둔 뒤에도 시계가 가고 사진이 바뀜
- [ ] 허브를 1분 껐다 켬 → "연결 확인 중"이 떴다가 저절로 사라짐
- [ ] `check=1` 을 지우고 저장

끝나면 반드시 `check=1` 을 지운다. 붙어 있는 동안 LED에 숫자가 계속 보인다.
