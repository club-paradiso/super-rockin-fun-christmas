# FOLLOW THE LIGHTS 현장 운영 안내 (초안)

> **초안이다.** 화면 이름과 버튼 이름은 지금 코드에 맞춰 두었다(2026-10-13). 아직 없는 것: "행사 종료
> 처리"(Phase 5). 현장 리허설에서 한 번 따라 해 본 뒤
> "초안" 표시를 뗀다. 처음 설치는 맨 아래 "10. 설치 (기술 담당)"를 본다.

컴퓨터를 잘 몰라도 이 순서대로만 하면 된다. 막히면 마지막 "도움 요청" 칸의 연락처로 연락한다.

## 0. 기기 한눈에 보기

| 기기                        | 하는 일                                             | 어디에                |
| --------------------------- | --------------------------------------------------- | --------------------- |
| **부스 노트북** (허브 겸용) | 사진 촬영 화면 + 모든 사진과 기록을 저장하는 "허브" | 포토부스              |
| 웹캠, 조명                  | 부스 노트북에 연결                                  | 포토부스              |
| **미디어월 PC**             | LED에 화면을 보냄                                   | LED 옆                |
| **전용 공유기**             | 부스·벽·스태프 휴대폰을 잇는 현장 전용 와이파이     | 부스 근처             |
| **스태프 휴대폰**           | 사진 검수, 비상 스위치                              | 스태프 주머니         |
| USB 메모리                  | 허브 자동 백업                                      | 부스 노트북에 꽂아 둠 |

전용 공유기 와이파이 이름과 비밀번호는 스태프만 안다. 성도에게 알려주지 않는다.

## 1. 아침에 켜기 (약 10분)

순서가 중요하다. **공유기 → 부스 노트북 → 미디어월 PC → 스태프 휴대폰.**

1. 공유기 전원을 켠다. 불이 다 들어올 때까지 1~2분 기다린다.
2. 부스 노트북을 켜고 바탕화면의 **`허브와 부스 시작`** 아이콘을 더블클릭한다.
   - 검은 창(허브)이 뜨고, 잠시 뒤 촬영 화면이 전체화면으로 뜬다.
   - **검은 창은 닫지 않는다.** 닫으면 모든 기기가 멈춘다. 최소화는 괜찮다.
   - 검은 창에 표시된 **허브 주소**(예: `http://192.168.0.10:3000/admin`)를 확인한다. 어제와 다르면
     미디어월 PC의 `wall-hub.txt`도 고쳐야 한다(10번 "고정 주소"를 해 두면 바뀌지 않는다).
   - 이미 켜져 있는데 또 누르면 "허브는 이미 켜져 있어요"라고 나오고 촬영 화면만 다시 뜬다.
3. 미디어월 PC를 켜고 **`미디어월 시작`** 아이콘을 더블클릭한다. LED에 밤하늘 장면이 뜬다. 브라우저가
   꺼지면 5초 뒤 저절로 다시 뜬다. 처음 한 번은 미디어월 등록이 필요하다(`docs/ADMIN.md`).
4. 스태프 휴대폰을 전용 와이파이에 연결하고 `허브 주소/admin`을 연다(홈 화면에 추가해 두면 편하다).
   이름을 고르고 PIN을 입력한다.
5. **점검** (관리자 화면 첫 페이지 "상태판"):
   - [ ] 부스: **온라인**
   - [ ] 미디어월: **온라인**
   - [ ] QR 서버 (인터넷): **밀린 일이 없어요**. "QR 대기"가 있으면 "6. 인터넷 끊김"을 본다. (이 칸은
         밀린 건수만 보여 준다. 인터넷이 되는지는 6번 시험 촬영에서 QR이 나오는지로 확인한다.)
   - [ ] 백업 · 저장 공간: 제목 옆에 **확인 필요**가 없다(마지막 백업이 30분 안, 노트북·USB 공간 충분)
   - [ ] 비상 스위치: 모두 꺼짐 (빨간 띠가 없어야 한다)
6. **시험 촬영 1회:** 스태프가 직접 찍는다. 휴대폰 **와이파이를 끄고**(데이터로) QR을 찍어 사진이 열리는지
   본다. 벽 노출에 "네"를 고르고 관리자에서 승인해 LED에 나오는지 본다. 확인 후 그 사진은 **삭제**한다.

## 2. 운영 중

### 사진 검수 (관리자 → 검수)

- 벽에 나가겠다고 한 사진만 여기 들어온다. **승인한 사진만** LED에 나간다.
- **승인하지 않는 사진:** 얼굴이 아닌 부적절한 내용, 장난, 다른 사람 사진을 찍은 것. 그리고 **어린이가
  보이는데 보호자 확인이 안 된 사진** (교회 기준이 정해지기 전까지의 임시 규칙).
- 목표: 들어온 지 2분 안에 처리. 혼자 감당이 안 되면 "벽 노출 접수 일시정지"를 켠다(촬영과 QR은 계속된다).

### 바로 띄우기

손님이 "제 사진 언제 나와요?" 하면 관리자 → 최근 사진에서 그 사진의 **지금 띄우기**를 누른다. 10초 안에
LED에 나온다. 승인된 사진만 가능하다.

### 미디어월 운영 시간

- 관리자 → 설정 → **미디어월 운영 시간**에서 시작·끝 시각을 정한다(한국 시간). 끝이 시작보다 이르면
  자정을 넘긴다(예: 18:00~01:00). 정하지 않으면 언제나 켜져 있다.
- 시간 밖에는 LED에 사진 없이 "오늘의 미디어월은 여기까지예요 · 17:00에 다시 불을 밝힐게요"가 나온다.
- 행사가 늦게 끝나거나 일찍 닫아야 하면 관리자 첫 화면 긴급 제어의 **미디어월 켜기/끄기**에서 **계속
  켜기** 또는 **끄기**. 다음 날 아침 **자동 (운영 시간)**으로 되돌려 놓는다(그대로 두면 시간표를 무시한다).
- 바꾼 내용은 5초 안에 LED에 반영되고 감사 기록에 남는다.

### 스태프 도움 모드 (부스 화면)

1. 부스 화면 **왼쪽 위 모서리**를 손가락으로 **3초 동안** 누르고 있는다(짧게 누르면 아무 일도 없다).
2. 내 이름을 누르고 PIN 6자리를 누른다. 틀리면 "PIN이 맞지 않아요"가 나온다. 5번 틀리면 15분 잠긴다.
3. 메뉴:
   - **카메라:** 웹캠이 여러 개일 때 고른다. 고른 카메라는 이 기기에 기억된다.
   - **보내지 못한 것:** 허브에 아직 안 간 사진과 미디어월 답변. **지금 다시 보내기**로 바로 보낸다.
   - **처음으로:** 지금 찍던 사진을 버리고 첫 화면으로. 보내는 중이던 사진은 계속 보낸다.
   - **화면 새로고침:** 화면이 이상할 때. 보낼 사진은 기기에 남아 있다.
4. 다 쓰면 **닫기**. 1분 동안 아무것도 안 누르면 저절로 닫힌다.

### 자동 삭제 (허브가 켜져 있는 동안 10분마다)

개요 "마지막 자동 정리" 아래에 지금 설정된 규칙이 그대로 나온다. 기본값:

- 미디어월에 안 나간 사진(동의 안 함, 거절, **검수 대기**): 촬영 24시간 뒤 삭제. 검수를 하루 넘게 미루면
  그 사진은 벽에 못 나가고 지워진다.
- 미디어월 사진(승인, 숨김): 행사 종료 시각 + 24시간에 삭제.
- 어떤 사진이든 촬영 30일(`PHOTO_RETENTION_DAYS`)을 넘기지 않는다.
- 노트북이 꺼져 있던 동안 지울 차례가 된 사진은 다음에 켤 때 30초 안에 지운다.
- 손님에게 "벽에 안 나간 사진은 하루 뒤, 벽에 나간 사진은 행사가 끝나고 하루 뒤 지워져요"라고 안내할 수
  있다(교회 확정 전 제안값).

### 1시간마다 볼 것

- 상태판에 빨간색이 없는지
- 촬영 화면 오른쪽 위에 **전송 대기** 표시가 계속 늘지 않는지
- 웹캠 렌즈가 가려지거나 돌아가 있지 않은지, 조명이 켜져 있는지

## 3. 저녁에 끄기

1. 관리자에서 **검수 대기 0건**인지 확인한다(남은 것은 승인 또는 거절).
2. 개요의 "QR 서버 (인터넷)"이 **밀린 일이 없어요**인지 확인한다. "QR 대기"나 "삭제 대기"가 남아 있으면
   인터넷이 될 때까지 기다리거나, 내일 아침 켜면 이어서 보낸다. 삭제 대기가 남은 채 행사를 끝내지 않는다.
3. 개요 "백업 · 저장 공간"의 **지금 백업**을 누르고 "백업했어요"가 나오는지 본다. 10분마다 저절로도
   하지만, 끄기 직전 것을 남기기 위해서다.
4. 미디어월 PC → 부스 노트북 순서로 **시스템 종료**한다. 공유기는 마지막에 끈다.
5. USB 메모리는 꽂아 둔다. (분실 위험이 있으면 책임자가 보관하고 아침에 다시 꽂는다.)

## 4. 이럴 땐 이렇게

| 증상                                 | 해야 할 일                                                                                                     |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| 촬영 화면에 "카메라를 확인해 주세요" | 웹캠 USB를 뺐다 다시 꽂고 화면의 **다시 시도**. 안 되면 "스태프 도움 모드"(아래)에서 **카메라** 고르기         |
| 촬영 화면이 멈춤                     | "스태프 도움 모드"에서 **화면 새로고침**. 그래도 안 되면 키보드 `F5`                                           |
| 촬영 화면이 아예 꺼짐                | 바탕화면의 **`허브와 부스 시작`** 다시 더블클릭                                                                |
| LED 화면이 끊기거나 버벅임           | 허브 `.env.local`에 `WALL_LITE=1`을 넣고 허브를 다시 켠다(저사양 모드: 반짝임·흔들림 없음, 사진 4장까지)       |
| LED가 검게 나오거나 멈춤             | 10초 기다린다(자동 복구). 안 되면 미디어월 PC에서 **`미디어월 시작`** 다시 더블클릭                            |
| LED에 "STAFF · 연결 확인 중"         | 공유기 전원과 미디어월 PC 와이파이 확인. 2분 넘으면 장면만 보이고 사진은 내려간다(정상 동작)                   |
| 잘못된 사진이 LED에 나옴             | 관리자 첫 화면 **미디어월 일시정지** (5초 안에 사진이 모두 내려감). 그다음 그 사진 **삭제**                    |
| 손님이 사진을 내려 달라고 함         | 관리자 → 최근 사진에서 찾아 **삭제**. LED와 QR 링크 모두 사라진다(인터넷이 끊겨 있으면 QR 링크는 돌아온 뒤)    |
| QR이 "준비 중"에서 안 넘어감         | "6. 인터넷 끊김"                                                                                               |
| "QR 서버의 보관 기간이 끝나…"        | 클라우드 사본이 보관 기간(기본 1일 권장)이 지나 지워졌다. 그 사진의 새 QR은 만들 수 없다. 사진은 노트북에 있다 |
| 관리자 PIN을 잊음                    | 책임자에게 요청. 책임자가 관리자 → 설정 → 스태프에서 새 PIN 발급                                               |
| 스태프 휴대폰 분실                   | 다른 기기로 로그인 → 설정 → 스태프 → 분실한 사람 **비활성화**                                                  |
| 상태판 "디스크 공간 부족"            | 기술 담당에게 연락. 사진은 지우지 않는다                                                                       |

## 5. 정전·재부팅

전원이 돌아오면 "1. 아침에 켜기" 1~5번을 그대로 한다. 저장된 사진과 기록은 그대로 남아 있다. 정전 순간
찍고 있던 촬영 한 건은 처음부터 다시 찍는다.

## 6. 인터넷 끊김

- **촬영, 벽 노출 선택, 검수, LED는 그대로 된다.** 안 되는 것은 QR 하나다.
- 부스 화면은 "QR을 준비하고 있어요"가 되고, 인터넷이 돌아오면 그 화면에 QR이 저절로 나온다(3초마다
  다시 물어본다). 가짜 QR은 절대 나오지 않는다.
- 손님이 기다리기 어려우면 **"QR 없이 다음으로"**를 누르게 하고, 화면 아래 **세션 번호 8자리**를 사진으로
  찍어 두거나 적어 가게 한다. 사진은 노트북에 저장돼 있다.
- 손님이 나중에 다시 오면: 관리자 → 최근 세션에서 세션 번호로 찾아 **QR 다시 보여주기**. 인터넷이 아직
  안 되면 "인터넷 연결이 안 돼서 새 QR을 만들 수 없어요"가 나온다. 인터넷이 돌아온 뒤 다시 누른다.
- 공유기의 인터넷 선(WAN)이 빠졌는지, 교회 인터넷이 되는지 확인한다.
- 인터넷이 돌아오면 밀린 사진이 15초 간격으로 자동으로 올라간다. 개요 "QR 서버 (인터넷)"이 **밀린 일이
  없어요**가 되면 끝이다.
- 세션 번호 없이 떠난 손님의 사진은 나중에 전달할 방법이 없다. (연락처를 받지 않기 때문이다.)

## 7. 허브 노트북이 고장 났을 때

1. 다른 노트북을 준비한다(10번 설치를 해 둔 예비 노트북이면 가장 빠르다).
2. 고장 난 노트북의 USB 백업 메모리를 새 노트북에 꽂는다.
3. 바탕화면 **`백업에서 복구`** 를 더블클릭하고, USB 위치(예: `E:\`, `/Volumes/FTL-BACKUP`)를 입력한 뒤
   `y`. 새 노트북에 있던 데이터는 지우지 않고 옆 폴더로 옮겨 둔다.
4. **`허브와 부스 시작`**. 마지막 백업 이후(최대 10분)에 찍은 사진은 고장 난 노트북에 남아 있다.
5. 미디어월 PC의 `wall-hub.txt`와 스태프 휴대폰을 새 **허브 주소**로 바꾼다. 부스는 새 노트북의
   브라우저에서 다시 등록한다. 미디어월은 허브 주소가 바뀌었으면 다시 등록한다(`docs/ADMIN.md`). 스태프
   이름과 PIN은 백업에 들어 있다.

## 8. 행사 끝난 뒤 데이터 삭제

교회가 정한 보관 기간에 따른다(지금 제안값: 벽 게시 사진은 행사 종료 후 24시간 안에 파기). 허브에
`EVENT_END_AT`이 설정돼 있고 허브가 켜져 있으면 그 시각 + 24시간에 허브가 스스로 지우고 클라우드 삭제도
보낸다. 아래 1번은 아직 없는 기능이다(Phase 5).

1. 관리자 → 설정 → **행사 종료 처리**. 클라우드의 모든 사진과 링크가 지워진다(인터넷 필요).
2. 허브 노트북의 사진 폴더(`FTL_DATA_DIR`, 기본 `.data`)와 USB의 `ftl-backup` 폴더를 삭제한다(기술
   담당, 절차는 Phase 5에서 스크립트로 만든다). 백업은 허브에서 지운 사진을 다음 백업 때 함께 지운다.
3. 빌린 노트북은 반납 전에 이 프로그램 폴더와 브라우저 데이터를 지운다.
4. 삭제한 날짜와 담당자를 기록한다.

## 10. 설치 (기술 담당, 행사 전 한 번)

부스 노트북(허브 겸용), 예비 노트북, 미디어월 PC에 한 번 해 둔다. 인터넷이 되는 곳에서 한다.

**부스 노트북 (허브)**

1. Node.js 22 LTS와 Chrome(또는 Edge)을 설치한다.
2. 이 프로그램을 받는다(`git clone` 또는 zip). 폴더에서 `npm ci` 를 실행한다.
3. `.env.example`을 복사해 `.env.local`을 만들고 채운다. 최소한:
   - `FTL_ROLE=hub`, `PHOTO_STORE=local`
   - `KIOSK_SESSION_SECRET` (`openssl rand -base64 48`)
   - `HUB_BACKUP_DIR` (USB 메모리 위치, 예: `E:\` 또는 `/Volumes/FTL-BACKUP`. 꽂혀 있어야 한다)
   - `EVENT_END_AT` (행사 종료 시각, 예: `2026-12-25T22:00:00+09:00`)
   - QR을 클라우드에서 받으려면 `CLOUD_BASE_URL`, `HUB_SYNC_SECRET` (`docs/DEPLOYMENT.md`)
4. `ops/start-hub.bat`(Windows) 또는 `ops/start-hub.command`(macOS)의 바탕화면 바로가기를 만들고 이름을
   **`허브와 부스 시작`** 으로 바꾼다. `ops/restore-backup.*` 은 **`백업에서 복구`**.
   macOS에서 처음 한 번은 오른쪽 클릭 → 열기(보안 경고 때문).
5. 한 번 실행한다. 처음에는 몇 분 동안 준비한다. 검은 창에 **첫 스태프 설정 코드**가 나오면 스태프
   휴대폰에서 `/admin/login`으로 첫 스태프를 만든다. 부스 화면이 뜨면 카메라 허용을 누른다(한 번만).
6. 전원 설정: 절전·화면 꺼짐 끄기, 덮개를 닫아도 계속 켜짐. 행사 기간 Windows 업데이트 일시 중지.
7. **예비 노트북**에도 1~4번을 똑같이 하고, `.env.local`은 부스 노트북 것을 그대로 복사한다. 이 파일의
   비밀값은 USB 백업에 들어 있지 않다(분실 시 사진과 열쇠가 같이 새지 않도록).

**전용 공유기:** 부스 노트북에 **고정 주소**(DHCP 예약)를 준다. 그래야 허브 주소가 매일 같다.

**미디어월 PC:** Chrome(또는 Edge)만 있으면 된다. `ops/start-wall.bat`, `ops/start-wall.ps1`,
`ops/wall-hub.txt` (macOS는 `start-wall.command`, `wall-hub.txt`)를 한 폴더에 복사하고, `wall-hub.txt`
첫 줄을 허브 주소(예: `http://192.168.0.10:3000`)로 고친다. `start-wall` 바로가기 이름은
**`미디어월 시작`**. 절전 끄기. 미디어월 등록은 `docs/ADMIN.md`.

**LED 해상도:** LED 담당에게 받은 입력 해상도를 허브 `.env.local`의 `WALL_CANVAS`(예: `3840x1080`)에
적는다. 정하기 전에 현장에서 여러 크기를 보려면 미디어월 PC 브라우저에서 `허브 주소/wall?canvas=3840x1080`
처럼 열어 본다. 빨랫줄에 걸리는 사진 수는 화면 비율에 따라 저절로 정해진다(16:9는 3장, 32:9는 8장, 4:1은
9장). 실제 관람 거리에서 얼굴이 알아볼 만한지 보고, 작으면 `config/wall.ts`의 `photoHeight`를 키운다.

**확인:** 1번 "아침에 켜기"를 처음부터 끝까지 한 번 해 본다. 개요의 "백업 · 저장 공간"에 마지막 백업
시각이 나오는지 본다(켜고 1분 뒤 첫 백업).
